# 节点地图

备团时可创建地图，主持人也可在运行时按需要创建或更新，不要求每轮展示。默认文件为 `/workspace/节点地图.json`；也可为不同区域建立独立 JSON 文件。地图文件只供主持人读取，玩家只看到 `show_map` 成功发布时的公开快照。

文件根为数组，每个元素使用以下字段。ID 唯一且非空，表面名字非空；表面描述和剧情笔记为字符串，可为空；连通性为已存在的目标 ID 数组；是否隐藏必须是真正的布尔值。位置参考坐标可省略，填写时为有限数值对象 `{ "x": 0, "y": 0 }`，数值绝对值不超过 1e9；x 向右、y 向下，可使用 0、1、2 等相对坐标，无需换算成像素。界面按节点范围和视口自动确定比例尺，节点、文字与箭头采用独立的屏幕尺寸。坐标仅作示意，不代表真实距离或玩家已知的精确方位；有坐标的地点保留相对位置，缺失或重合的坐标自动排布。

```json
[
  {"表面名字":"庭院","ID":"courtyard","表面描述":"石径通往门廊。","剧情笔记":"","连通性":["hall"],"位置参考坐标":{"x":0,"y":0},"是否隐藏":false},
  {"表面名字":"门厅","ID":"hall","表面描述":"入口处有一盏壁灯。","剧情笔记":"主持人内部的事件与调查线索。","连通性":["courtyard","cellar"],"位置参考坐标":{"x":180,"y":0},"是否隐藏":false},
  {"表面名字":"地下室","ID":"cellar","表面描述":"潮湿的石阶。","剧情笔记":"入口尚未被发现。","连通性":["hall"],"是否隐藏":true}
]
```

`show_map({"current_id":"courtyard"})` 展示默认文件；`show_map({"path":"区域地图.json","current_id":""})` 展示其他文件且不高亮地点。current_id 不可省略，有值时必须对应存在且未隐藏的节点。文件不存在、JSON 或字段不合法、ID 重复、连接目标不存在时，工具拒绝整个展示，不生成半张地图。空数组配合空 current_id 合法。

连通性默认单向。两端互相列出时绘成无箭头的双向连接。所有隐藏或剧透地点事先标为 `是否隐藏:true`，其节点、名字、描述和关联连线均不会交付玩家；剧情笔记永远不进入公开快照。到达或发现后，在符合知情范围的情况下可取消隐藏，再发布新地图。公开名字和描述也只能包含玩家已知事实，不写内部提示或剧透。

地图向所有玩家及观众公开；只有某位玩家知道的位置不可在公共地图揭露，也不以公共高亮泄露秘密行动。多人分处不同地点时，可将 current_id 留空。地图只是信息展示，不替代正文、行动结算或权限判断。

每次成功展示都是一张不可变的故事地图卡片。后续文件修改只影响下一次展示，旧快照不会增加新公开地点。玩家可从行囊底部按钮回看最近快照，点击卡片打开可拖动、缩放的详情，节点详情只显示表面名字和描述。导出 HTML 中地图卡片需长按 3 秒打开（总览模式同样如此），滚动或移动手指取消长按；工具栏的查看地图按钮仍可一键打开。
