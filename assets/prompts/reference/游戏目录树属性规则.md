### 角色数值的唯一归属（适用于 Player、KPC 与 NPC）

- **同一角色的同一项当前数值只存一份**，不得在 `属性`、`衍生属性`、`状态` 之间复制，也不得用大小写或中英文别名另建一份。HP 与 MAXHP 分别代表当前值与上限，不是重复字段。
- 规则书中的“衍生属性”说明数值的计算来源，不决定 JSON 分组。即使 HP、MP、SAN 由基础属性计算得出，也必须按上表只写入 `状态`；伤害加值、体格、移动等写入 `衍生属性`。
- 建卡、受伤、恢复、理智变化与属性重算时，读取并更新唯一归属位置。不要为了兼容格式校验而向其他分组补写副本；字段已存在时不另建同义键。仅采用对应规则时才增加 SAN/MAXSAN 等体系专属指标。
- 维护已有角色时，若发现重复且数值一致，保留唯一归属位置的值并移除其他分组的冗余字段；若唯一归属位置缺失且其他位置有唯一明确的值，则迁入原值。若数值冲突，先核对最近的角色日志和回合结算确定当前有效值，再统一，不能直接取较大值、取上限或按建卡公式重置当前值；无法确定时保留现场并报告冲突，不猜测覆盖。
- 此规则约束 `基础信息.json` 内当前角色数值的存储；日志中的历史数值、技能消耗和 Buff 修正不是当前值副本，不应据此删除。

| (Index: n) | **名称** (Name/BuffID) | String | 状态名称 | "狂暴", "中毒", "虚弱" |
| | **描述** (Desc/EffectText) | String | 视觉与叙事表现描述 | "双眼通红，力量大增，但失去理智。" |
| | **.是否对玩家隐藏** | Boolean | 仅适用于 Buff 条目的可选字段，用于隐藏不明显、尚未诊断或包含剧透的内容。 |
| | **修正** (Modifier/StatsMod) | Object | 数值偏移 (Buff/Debuff Value) | `{"STR": +5, "INT": -2, "DEF": "x0.8"}` |
| | **剩余时间** (Duration/TurnsLeft) | Number/Str | 持续回合或时间戳 | `5` (表示5回合), `-1` (表示永久/种族特质) |
| | **触发频率** (TickRate/Interval) | Number | (可选) 每隔几回合生效一次 | `1` (每回合扣血) |
| | **.隐藏效果** (HiddenEffect/.HiddenEffect) | String | 玩家不知道的额外效果 | "角色变得敏感", "每回合累计1%异变进度" |
| | **.当结束时** (WhenEnd/.WhenEnd) | String | 状态结束时触发的额外效果，或触发下一阶段的Buff | "角色恢复正常状态", "角色获得疲劳", "获得Buff‘变异阶段-2’持续10回合" |
| | **.进度** | Number/Str | 主持人记录该 Buff 当前的积累进度或所处阶段；点前缀表示对玩家隐藏 | `25`（需由该 Buff 规则明确单位）、`"25%"`、`"第二阶段"`；按实际触发条件更新，不等同于剩余时间，增长到一定程度可能会触发特殊事件。 |
| **主动技能** | - | **Array[Obj]** | Abilities, CombatSkills, 可用招式 | 实体可以主动选择执行的指令集。 |
| (Index: n) | **名称** (SkillName/ActionID) | String | 技能唯一识别名 | "火球术", "绝命格挡" |
| | **描述** (FlavorText/Effect) | String | 技能动作及效果的文字说明 | "汇聚火元素，对远程目标造成爆炸伤害。" |
| | **修正** (Modifier/CombatMod) | Object | 判定加值或伤害系数 | `{"HIT": +2, "DMG": "2d6+4", "Target": 1}` |
| | **消耗** (Cost/Resources) | Object | 执行代价 (MP/HP/Stamina) | `{"MP": 15, "SP": 10}` |
| | **冷却** (Cooldown/CD) | Number | 再次使用需等待的轮数 | `3` (使用后需等待3回合) |
| | **当前冷却状态** (CooldownStatus/CooldownState) | String | 技能当前冷却状态 | "就绪", "剩余5回合", "2077年1月1日13:00恢复" |
| | **范围** (Range/Area) | String/Num | 攻击距离或波及范围 | "远程-15米", "自身周身-5米" |
| | **前置条件** (Requirements/Pre) | String | 施放限制条件 | "必须装备盾牌", "仅限夜晚" |
| | **.隐藏效果** (HiddenEffect/.HiddenEffect) | String | 玩家不知道的额外效果 | "对亡灵目标额外造成10点伤害", "累计1%异变进度" |
