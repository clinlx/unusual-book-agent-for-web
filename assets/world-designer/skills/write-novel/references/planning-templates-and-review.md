# 长篇规划模板与自检清单

**适用层级**：主要用于 L3、L5 和 L7。
**解决问题**：长篇模板、逐卷流程、人物编排输出、伏笔账本、情绪线账本、自检清单。
**不解决**：不替代前置创意提炼，也不直接负责正文风格执行。
**缺前置时**：若核心乐趣或主线承诺还不清楚，先回看 meme-and-commercial-funnel.md 与 standard-workflow.md。
**账本持久化**：爽点档案、伏笔账本、情绪线账本都是跨轮状态。每次更新后作为交付物完整输出，或写入用户项目里的账本文件；下一轮从用户提供的账本恢复，不要依赖对话记忆。

条目：§T1 初始设定输出 ｜ §T2 人物编排输出 ｜ §T3 逐卷流程 ｜ §T4 伏笔账本 ｜ §T5 情绪线账本 ｜ §T6 自检清单

## 长篇规划模板

默认长篇可按 8 卷、每卷约 100 章、每章约 2000 字、总计约 160 万字规划；若用户给出篇幅，以用户为准。

### §T1 初始设定输出

```text
- 一句话卖点：
- 目标 meme：
- 目标读者乐趣：
- 主爆点：
- 关系内核：
- 开头 10 章大纲：
- 核心悬念：
- 主角缺陷与欲望：
- 至少 5 个世界观谜团：
```

### §T2 人物编排输出

```text
- 主角：欲望 / 缺陷 / 身份限制 / 价值冲突 / 关系张力
- 关键配角：剧情功能 / 个人欲望 / 与主角的冲突或互补
- 反派或阻碍者：正确之处 / 错误之处 / 不可退让之处
- 人物冲突矩阵：谁和谁冲突、因为什么、是否有理解机会
```

### §T3 逐卷流程

```text
第 N 卷：
- 本卷副爆点：
- 靠近但不释放的主爆点部分：
- 本卷主导情绪线（从哪条长期情绪细化而来，子目标是什么）：
- 卷末情绪迁移（把哪条情绪承上启下给下一卷，过渡空窗由哪条线覆盖）：
- 主要误导：
- 新增人物关系变化：
- 本卷需要埋设的伏笔：
- 本卷需要回收的伏笔：
- 卷末新谜团或更深线索：
```

### §T4 伏笔账本

每卷末维护一次，标记每条伏笔"已埋、已提醒、已误导、已回收、待回收"（埋设与伪装技法见 §N1 前置伪装）。

```text
伏笔：
- 首次出现章节：
- 表层含义：
- 真实用途：
- 误导方向：
- 提醒节点：
- 回收章节：
- 回收时的情绪效果：
```

### §T5 情绪线账本

每卷末与伏笔账本同步维护一次。逐条登记正在运行的情绪线，重点检查两件事：每条线的建立期和过渡期由谁覆盖，是否存在全线同时低谷的空窗章节。

```text
情绪线：
- 层级：长期主线 / 卷级 / 阶段子目标
- 源头欲望（读者从哪一章开始想要，第一共鸣如何建立）：
- 传承来源（从哪条情绪承上启下而来，传承链是什么）：
- 当前子目标：
- 当前状态：建立 / 升温 / 高潮 / 过渡
- 空窗覆盖（本线建立期和过渡期由哪条线的高潮顶上）：
- 提醒节点（子目标燃烧时，如何让读者记得上层情绪仍未解决）：
- 兑现节点（哪一章兑现，对应主爆点还是副爆点）：
- 兑现后去向（回归哪条长期情绪，或迁移成哪条新线）：
```

## §T6 自检清单

每章或每卷完成后检查：

- [ ] 是否过早释放主爆点？是否需要改成副爆点补偿？
- [ ] 是否先确定了 meme，再选择题材要素，而不是反过来堆元素？
- [ ] 是否形成"快来了—被阻断—局部爆发—更期待"的拉扯？
- [ ] 长期情绪是否细化为子目标欲望？子目标完成后是否回到长期情绪？
- [ ] 新情节段的驱动力是否从已有情绪承上启下而来，而不是凭空开始？
- [ ] 是否存在所有情绪线同时处于建立期或过渡期的空窗章节？
- [ ] 开头或章末是否同时具备设定、情绪、问题中的至少两种钩子？
- [ ] 开头是否迅速建立第一共鸣？读者是否同时做到感兴趣、关心、理解？
- [ ] 人物行为是否由欲望、缺陷、身份、信息差或价值观驱动？
- [ ] 关键人物是否有多层动因，而不是单一标签？
- [ ] 冲突是否双方都有理由，是否存在"如果能理解就会更惋惜"的空间？
- [ ] 伏笔是否有表层意义、真实用途、误导方向和回收计划？
- [ ] 是否有前置伪装的关键人物、物品或规则，并在足够长的间隔后再揭示真正意义？
- [ ] 是否有足够的误导和烟雾弹，但回看仍公平？
- [ ] 是否写了短期不爽、尴尬、失败或代价，以增强后续释放？
- [ ] 世界观设定是否通过节奏、人设、社会结构三重审视？
- [ ] 世界观是否通过行动、互动、观赏展示，而不是纯解说？
- [ ] 核心谜团是否仍保持神秘，并与人物命运相关？
- [ ] 元素融合是否先抓 meme 和关系内核，再用机制和世界观换壳？
- [ ] 是否能看出原型？若能，是否已改变关系位置、舞台、代价和限制？
- [ ] 战斗是否依赖环境、判断和代价，而不是喊招式名？
- [ ] 情感互动是否克制、具体，并推动关系变化？
- [ ] 正文是否按镜头组织画面？镜头切换是否渐进、每个镜头是否有明确的情绪目标？
- [ ] 正文是否全程收在视角人物的感官与认知内？有没有任何一句她不可能知道的叙述（§P7）？
- [ ] 内心活动加引号读，像不像活人对自己说的话？有没有叙述者替人物分析、总结、升华（§P7）？
- [ ] 同一个叙事节拍是否只讲了一次？有没有"行动—感受—分析—总结"复读（§P7）？
- [ ] 信息是否按场景需要逐粒释放、通过主角的发现喂出？决定和场景转换是否靠动作与因果、而不是叙述宣布（§P8）？
- [ ] 成稿是否扫过句式黑名单？转折定义式、否定排比式、直接程度副词、越出人物认知的比喻是否已改写为具体细节（§P9）？
- [ ] 场景里是否有不服务剧情的闲笔细节让世界显得活着？氛围是否靠气味、声音、触觉叠出而不是形容词宣布（§P10）？
- [ ] 主角脱困是否全部来自已埋的伏笔、能力或关系？有没有敌人降智、巧合救场的机械降神（§P10）？
- [ ] 每个场景是否立了盒子（空间、在场者、进场状态）？戏是否在场景里演到有变化才换景？人物有没有凭空出现或用完即蒸发（§P11）？
- [ ] 相邻场景是否有时间、空间或因果连续性？转场是否有过场缝合而不是硬切？一章是否超过 3 个场景（§P11）？
- [ ] 本章结尾是否让读者想立刻翻下一章？章末钩子是否由故事材料（动作、台词、所见之物、新念头）构成，而不是叙述者旁白宣告（§P7）？
- [ ] 每卷结束时是否做过一次伏笔回收检查，确认哪些已埋、已提醒、已误导、已回收、待回收？
- [ ] 每卷结束时是否更新过情绪线账本，确认每条线的当前状态、空窗覆盖和兑现去向？
- [ ] 修改类任务动手前是否核对过连锁影响（伏笔、情绪线、既有事实）？破坏性修改是否经过商讨确认？
