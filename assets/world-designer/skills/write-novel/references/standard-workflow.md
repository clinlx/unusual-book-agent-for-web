# 标准工作流与长线爆点管理

**适用层级**：主要用于 L2-L5。
**解决问题**：核心乐趣转结构、开头 10 章组合拳、名场面反推、主爆点与副爆点、情绪线管理、一波三折与新坑续命。
**不解决**：不替代世界观细节库，也不直接处理最终文风措辞。
**缺前置时**：若任务边界和读者乐趣不清楚，先回看 collaboration-and-questioning.md 与 meme-and-commercial-funnel.md。

条目：§W1 识别核心乐趣 ｜ §W2 开头 10 章组合拳 ｜ §W3 反推名场面 ｜ §W4 主爆点与副爆点 ｜ §W5 情绪线管理（细化 / 承上启下 / 交替覆盖）｜ §W6 一波三折与新坑续命

## 标准工作流

### §W1 识别核心乐趣

接到题材、设定或改写任务后，先输出：

- **目标读者快感**：爽、甜、虐、燃、悬疑、羞耻、怜爱、征服、守护、成长、反转等。
- **目标 meme**：本次创作要复现或混合的底层感受、氛围、关系因子或精神气味。
- **主爆点**：全书或本卷最明确、最庞大、读者最期待的最终爆发。
- **关系内核**：读者真正迷恋的人物关系张力，例如支配/依赖、隐藏/暴露、亏欠/拯救、敌对/理解、仰望/堕落、保护/伤害。
- **持续发动机**：能反复制造这种张力的机制，例如身份隐藏、资源循环、阵营博弈、阶级差异、规则限制、追逃结构。
- **外壳变化**：把关系内核装进新的题材、世界观、职业、种族、制度或技术系统中。

### §W2 设计开头 10 章组合拳

开头 10 章不是“慢慢铺垫”的许可区，而是最密集的留人区。硬指标是：尽快让读者兴奋、快速建立吸引力、在第一卷前抛出核心悬念。

开头不能只靠单一钩子，至少组合三种吸引力：

- **设定钩子**：强身份、强异常事件、强规则、强世界差异。
- **情绪钩子**：兴奋、震惊、憋屈、羞耻、怜爱、恐惧、期待。
- **问题钩子**：为什么会这样、真相是什么、主角如何破局、某人到底隐瞒了什么。

开头 10 章输出格式：

```text
第 N 章：
- 表层事件：
- 场景表（1–3 个：地点｜时段｜在场者｜这场戏演出什么变化，见 §P11）：
- 触发的读者情绪：
- 新增设定吸引力：
- 本章新喂的信息块（读者理解下一章所必需的最小集，正文只兑现此清单，见 §P8）：
- 抛出的疑问：
- 隐藏的伏笔：
- 章末翻页钩子（正文落地时须由故事材料构成，禁止旁白宣告，见 §P7）：
```

章纲是脚手架，不是正文的节拍表。正文写的是主角在节拍之间的连续主观经历；把章纲逐条翻译成场景，就是流水账的直接成因（§P8）。一章的表层事件必须能装进 1–3 个场景演完，装不下就说明本章节拍超载，砍节拍，不要压缩场景。

### §W3 反推名场面

先设计 3-5 个核心名场面，再反推它们为何必然发生。

每个名场面必须包含：

- **画面**：读者能立刻想象的高冲击瞬间。
- **情绪类型**：燃、爽、虐、甜、震撼、羞耻、反杀、揭露、牺牲、重逢等。
- **关系变化**：人物之间的支配、依赖、理解、背叛、亏欠、保护关系如何改变。
- **因果链**：至少 5 个导致此场面的前置事件。
- **伏笔需求**：哪些人物、物品、规则、传闻、伤痕、台词必须提前出现。
- **延迟理由**：为什么不能现在释放，必须等到更高情绪压力时释放。

### §W4 建立长线主爆点与短线副爆点

主爆点是读者明确期待的最终大释放；副爆点是路上意外产生的小爆发。

核心手感不是“有高潮就行”，而是欲拒还迎：对于公认即将爆发的爽点，要反复擦边、持续预告、制造风雨欲来，再用阻断和误导把兑现尽量拉长，直到读者已经形成强烈催促感。

- **主爆点延迟释放**：让读者知道它会来，但不断用阻断、误导、代价、身份限制、局势升级延后兑现。
- **封存爽点**：想到好用的大爽点时，不要立刻写掉；先记入笔记或爆点表，等代价、期待和见证者都够了再释放。
- **副爆点意外补偿**：中途的小高潮不能提前消耗主爆点，而应来自计划受阻、伏笔误触、人物碰撞、局部胜利、意外反转。
- **拉扯节奏**：反复制造"快来了—被打断—更接近—又变复杂—局部爆发—继续等待"的循环。
- **释放标准**：当读者已经形成明确期待、人物代价足够重、局势无法再拖、前置伏笔足够密时，才释放主爆点。

可用节奏模板：

```text
预告主爆点 → 接近兑现 → 信息切断/计划失败 → 副爆点补偿 → 代价升级 → 新线索靠近主爆点 → 更大阻断 → 主爆点最终释放
```

### §W5 情绪线管理：细化、承上启下、交替覆盖

主线承诺、阶段目标、章节钩子在读者侧是同一种东西：情绪欲望。这里的情绪不是单指主角的情绪，而是全书基调和读者绑定——让读者看主角所看、想主角所想，拥有和主角一样的欲望和诉求。主角的目标目的性也是情绪的延伸：读者没有共情的目标，主角说破天读者也只会莫名其妙。在这个意义上，情绪可以视为目标、情节、意境的近义词。情绪分长期流程情绪和短期当下情绪两个尺度，都要显式管理。

#### 情绪细化

把长期情绪保留在背景，从中划分出子目标的欲望情绪；子目标完成后，注意力回到长期情绪，再切出下一个子目标。此操作可以递归，直到落到卷、阶段和章节。

- 主爆点是最长期情绪的最终兑现，副爆点是子目标情绪的局部兑现，细化链是两者之间的桥。
- 细化不是替换。子目标在前台燃烧时，要用提醒、代价或敌人动向让读者记得长期情绪仍未解决。

#### 情绪承上启下

把前一段情节的情绪，想办法转移注意力、迁移到下一段情节中去，完成驱动力的传递。示例传承链：

```text
女王要把我绑回家 → 女王有大军 → 我也要军队才能抵挡 → 必须发展生产力 → 粮食不够 → 土地制度限制生产力 → 土地改革
```

沿这条链，女王带来的威胁感被逐步转移到土地改革上。读者关心土地改革，不是因为种田本身有趣，而是它继承了“女王要来抓我”的原始欲望。

- 每开一段新情节先回答：它的驱动力从哪条已有情绪继承而来？凭空开始的情节段是断链，读者没有理由关心。
- 链条每一环都必须是读者已经共情的欲望；断掉一环，后面的情节就变成作者自嗨。
- 情绪不止一条，也不止一个层级；长期和短期情绪都可以被承上启下，并经常与细化结合使用。

#### 交替覆盖

情绪的建立需要铺垫，过渡需要迁移，这两段都是欲望低谷。如果让所有情绪线集中开始、集中过渡，读者会在空窗期短暂失去欲望，这是弃书的高危时刻。稳妥做法是多条情绪线交替进行，相互覆盖对方的过渡空窗，保证任何时刻至少有一条情绪处于高潮。

```text
A 线高潮时，B 线悄悄建立；A 线过渡传承时，B 线恰好进入高潮；B 线过渡时，由 C 线或回归的 A 线顶上。
```

- “旧事件收束前开新坑”是交替覆盖的最简形式；更完整的做法是把每条线的建立、升温、高潮、过渡显式排布（用 §T5 情绪线账本登记），检查有没有全线同时低谷的章节。
- 写每个场景时自问：当前画面窗口内哪条情绪在高位？哪条在过渡？过渡空窗由谁覆盖？

### §W6 一波三折与新坑续命

悬疑和拉扯的本质，经常只是“作者知道的信息暂时不告诉读者”。但不能直给，要让情绪弯曲前进。

- 不要写“女孩回头看见怪物”这种日记式直线。应先给低吼、翻动痕迹、误判、小猫、血迹，再让怪物出现。
- 一波三折不是机械反转，而是情绪高低交替：小负面 → 小正面 → 中负面 → 中正面 → 大负面/大期待。
- 不要让事件完全结束后才开新事件。读者常想“这个事件结束就睡”，所以要在旧事件收束前开新坑。
- 新坑可以只是预兆，不必立刻爆发。这样可以插入日常、发糖、回顾、走访朋友、了解局势等慢节奏内容。
- 没有真正的纯日常。日常应穿插在松弛主线里，承担关系推进、信息更新、伏笔提示或新危机预兆。

日常插入模板：

```text
正面轻松互动 → 异常预兆/意义不明的警告 → 表面解释成误会或骗局 → 角色继续放松 → 暗处证明预兆是真的
```
