# 叙事、人物、内容编排与世界观

**适用层级**：主要用于 L4，必要时可为 L5-L6 提供局部支撑。
**解决问题**：诡计叙事、前置伪装、人物缺陷、冲突来源、世界观服务情节、类型融合。
**不解决**：不单独决定全书主爆点或完整章节节奏。
**缺前置时**：若主线承诺和阶段结构还没稳定，先回看 granularity-orchestration.md 与 standard-workflow.md。

条目：§N1 叙事与伏笔（诡计叙事 / 前置伪装）｜ §N2 人物系统（类型 / 缺陷萌点库 / 暗面动因 / 冲突来源库）｜ §N3 内容编排（压制自我满足 / 困住角色 / 必备场面 / 身份跌落）｜ §N4 世界观构建（服务情节 / 三重审视 / 细节清单 / 展现方式 / 核心神秘）｜ §N5 元素融合

## §N1 叙事与伏笔

### 诡计叙事

目标是让读者觉得“结尾早在眼前，但过程完全没猜中”。最稳的结构通常是：开头明示一部分结果或危险，结尾让读者形成预感并急着翻页，过程绝不按直线预测发生。

- 开头可以明示部分结果、传闻、命运、身份碎片或未来场景。
- 结尾要让读者有预感并期待，不要凭空降临。
- 过程要用人物不确定性、信息差、场景切换、剪辑式误导制造多种可能。
- 可以制造“作者知道、主角知道、读者不知道”的悬念，但必须保证回看时公平。
- 可以故意安排看似指向性极强的线索，引导读者建立错误预期。
- 关键转折处可切换场景，暂时切断信息流，形成悬疑和错误预期。
- 只要因果仍成立，部分铺垫可以后移；重点是满足因果拓扑，而不是死守信息按时间顺序露出。

### 前置伪装

后期重要元素要尽量提前伪装出现：

- 后期重要人物可先以商人、路人、仆人、敌方杂兵、传闻对象、匿名帮助者等身份出现。
- 后期关键物品可先作为普通陈设、损坏道具、风俗物、纪念品、交易品一笔带过。
- 后期关键规则可先以笑谈、禁忌、童谣、仪式、失败案例、旧案记录出现。
- 伏笔埋下后不要立刻解释；长篇中可隔 30 章以上再揭示真正意义。
- 每卷末维护一次伏笔账本，标记"已埋、已提醒、已误导、已回收、待回收"；账本格式见 §T4（planning-templates-and-review.md）。

## §N2 人物系统

### 人物类型

- **圆形人物**：重要人物默认应有多重动因、缺陷、欲望和自洽立场。
- **扁平人物**：可用于功能性配角、喜剧节奏、信息传递、临时阻碍。
- **完美人物**：若存在，应承担强烈代价，例如注定离去、无法抵达、被误解、被历史吞没；不要让完美变成无成本偏爱。
- **脸谱原型**：可以使用常见角色类型，但必须叠加个人欲望、独特缺陷、具体关系和不可替代的剧情功能。

### 缺陷与萌点库

缺陷不是贴标签，而是制造选择偏差和关系张力的工具。可组合但不要堆满。

| 缺陷 | 可转化的戏剧功能 |
|---|---|
| 贪财 | 被利益诱惑，也能因珍惜资源显得可靠 |
| 贪吃 | 缓和气氛，暴露弱点，触发日常关系 |
| 好色 | 制造冲动、羞耻、误会，必须避免降智和冒犯 |
| 懒惰 | 逃避责任，与不得不行动形成反差 |
| 得过且过 | 缺乏长远目标，适合被重大事件逼醒 |
| 爱贪小便宜 | 引发小麻烦，也能成为生存智慧 |
| 容易吐槽 | 提供读者代言，但可能得罪人 |
| 性格恶劣 | 制造摩擦，后续用行动证明底线 |
| 嗜酒 | 暴露逃避、创伤或社交依赖 |
| 傲娇 | 口是心非，制造延迟表达和误会 |
| 爱面子 | 死撑尊严，适合被迫低头或付出代价 |
| 过度善良 | 在残酷环境中制造代价和争议 |
| 内向自闭 | 信息表达受阻，适合细腻心理描写 |
| 固执偏激 | 推动不可逆选择，制造悲剧感 |
| 天真 | 让世界残酷性更鲜明，也能保留纯粹价值 |
| 嘴臭 | 语言伤人但未必心坏，适合反差塑造 |
| 一心求死 | 想结束生命，但若不能死，就必须维护最后的尊严；内在矛盾本身就是强戏剧引擎 |

### 暗面动因

上表偏日常向。阴暗题材或反派塑造时，把傲慢、嫉妒、暴怒、懒惰、贪婪、暴食、色欲当作真实的生物驱动力承认，而不是贴在反派身上的罪名标签——它们会实际驱动侵扰、支配、背叛、杀戮，正派角色心里也可以闪过这些念头（闪过之后压下去或没压住，都是戏）。

- 暗面动因和上表缺陷一样要过"多层动因"检验：贪婪的人同时珍视什么？施虐的人恐惧什么？单一暗面即扁平。
- 暗面必须落到具体行动和后果，不停留在氛围形容；正文执行时对应 §P10"绝境不注水"——给了角色恶意动机，就要敢让它运转到底。
- 尺度对齐题材和平台；暗面服务冲突和代价，不服务猎奇（→§N3 残酷场面的写作要求）。

### 冲突来源库

任何一类人物都可能出场，关键人物甚至应兼备多层冲突。

- **价值观冲突**：双方都正确，但正确之间不可兼得。
- **性格缺陷冲突**：角色被骄傲、逃避、贪婪、天真、固执等推向错误选择。
- **身份责任冲突**：身份、阶级、阵营、承诺、恩情、职责让角色不能自由行动。
- **信息差冲突**：每个人基于不完整信息做出自认为正确的决定。
- **时代结构冲突**：个人选择被家国、制度、战争、资源、历史惯性放大。

关键问题：如果这些人有一次真正相互理解的机会，冲突会消失、变形，还是因为更大的结构而继续发生？

## §N3 内容编排

### 压制自我满足

作者不能只写自己即时想要的 YY。越大的爽点越要压住，越重要的满足越要付出铺垫。

- 主动打乱主角计划，不要让一切太顺。
- 让主角错过神器、机会、告白、真相或胜利；只有推动剧情和人物变化的获得才值得发生。
- 写一些短期不爽、尴尬、惋惜、误会、失败、退让，让后续爆发更有重量。
- 写自己未必偏爱、但目标读者可能喜欢的场面类型，并把它们纳入结构。

### 困住角色的高级方式

优先使用内在阳谋，不要只靠外在枷锁。

- 身份困住：他必须扮演某个角色，不能暴露真我。
- 责任困住：他有承诺、恩情、债务、使命、保护对象。
- 缺陷困住：他明知该改变，却被骄傲、恐惧、执念拖住。
- 道德困住：两个选项都正确，但只能选一个。
- 信息困住：他做出错误选择，是因为缺少关键事实。

### 必备场面类型

按题材选择覆盖，不必每章都写，但长篇应有意识调度。

| 场面类型 | 写作要求 |
|---|---|
| 温馨 | 提供安全感和关系沉淀，让读者愿意在乎角色 |
| 煽情 | 精准打击泪点，克制，避免喊口号 |
| 残酷 | 服务代价、恐惧和世界规则，不为猎奇而猎奇 |
| 中二 | 帅、燃、信念明确，让读者愿意代入喊出来 |
| 心机 | 每个人都在算计，且算计来自真实利益和信息差 |
| 情感暧昧 | 克制、拉扯、擦边不越界，重点在心理与细微动作 |
| 误会 | 逻辑自洽，不靠集体降智维持 |
| 打脸/屈辱 | 先立地位、轻视或克制的基线，反差才成立；爆发需要见证者和代价，事后必须改变关系或局势 |
| 发糖 | 自然、不刻意，是关系积累后的轻释放 |

### 身份跌落与重活

"死亡/重生/换身份/从顶点跌到底层"可用于丰富人生结构。

- 用高位视角展示秩序，用底层视角揭示代价。
- 让主角在不同身份中重新理解同一世界。
- 身份变化必须改变关系、资源、行动限制和价值判断。
- 两种视角最好指向同一套世界规则的不同真相，而不是只换职业皮肤。

## §N4 世界观构建

世界观不是创作起点，而是情节工具。不要先扎进设定死胡同；先写出好看的内容、明确读者体验、确定主线情绪，再补必要世界观。

### 服务情节原则

- 所有设定都必须服务情节、人物、冲突、情绪或主爆点。
- 不要创建一个世界后让角色“自由发展”；作者应精细构造读者体验，再让世界观解释、放大和承载它。
- 世界观不用写太多。读者先被事件、悬念、关系和情绪抓住，才会愿意了解设定。
- 玄幻、科幻、都市、赛博朋克都只是世界观外壳；真正重要的是它如何制造限制、欲望、压迫、反差和成就感。
- 如果一个设定不能制造更好看的情节，就删掉或延后。

### 三重审视

每个设定都要检查：

1. **节奏**：它会不会拖慢叙事？能否通过行动、冲突、对话、场景展示？
2. **人设**：它会不会让角色行为不合理？角色是否会自然利用、误解或反抗它？
3. **社会结构**：它会如何影响医学、战争、教育、贸易、阶级、婚姻、宗教、法律、人口？
4. **情绪功能**：它具体放大了哪种读者情绪？憋屈、期待、爽感、恐惧、怜爱、压迫、成就感，还是神秘感？

### 细节填充清单

| 类别 | 可写内容 |
|---|---|
| 地理 | 山脉由来、河流流向、城市命名、交通瓶颈 |
| 天文 | 星空、月亮数量、特殊天象、历法和禁忌 |
| 神话 | 创世传说、英雄史诗、种族起源、被篡改的神话 |
| 历史 | 辉煌时代遗迹、旧战争、失落技术、从土地里挖出的过去 |
| 海洋 | 潮汐规律、海中禁忌、航路、海怪和贸易 |
| 种族 | 来历、生理特征、习性、社会地位、歧视或特权 |
| 食材 | 特殊食材、来源、烹饪方式、文化含义 |
| 人口 | 迁移史、城市规模、族群分布、灾难后的变化 |
| 教育 | 学院制度、知识垄断、考试、师承、教育的阶级功能 |
| 经济 | 货币、贸易路线、资源垄断、黑市、税制 |
| 规律例外 | 在稳定规则中设置少量特例，制造惊喜和剧情入口 |

### 展现方式

不要大段说明世界观，优先用互动与观赏展示。

- 看星星时透露天文和历法。
- 吃饭时引出食材、阶级和地域。
- 路过遗迹时揭示历史断层。
- 战斗时让地理、天气、建筑结构影响胜负。
- 交易时展示货币、资源和权力结构。

### 保持核心神秘

全书最大谜团要长期存在。即使每卷解决局部问题，也要让读者感觉更深层的东西尚未结束。

- 每卷给出新线索，不要一次解释完。
- 每次解释都应带来更大的问题。
- 核心谜团要与人物命运、世界结构、主爆点相关，不能只是背景装饰。

## §N5 元素融合：新瓶装旧酒

借鉴时不要照搬表层。先抓 meme 和情感关系内核，机制和世界观只作辅助。真正要继承的是“为什么令人有感触”，不是“它用了什么题材道具”。

### 融合步骤

1. **记录原初感受**：这个片段给人的第一感受是什么？冰冷、温暖、宏大、寂寞、羞耻、燃、安心、荒诞、绝望、神圣？
2. **拆 meme**：这种感受背后的底层因子是什么？氛围、关系、价值观、叙事姿态、世界规则，还是某种时代精神？
3. **拆关系**：原型真正迷人的关系是什么？支配/依赖、隐藏/暴露、亏欠/拯救、敌对/理解、羞耻/渴望、保护/伤害？
4. **拆情绪**：读者在这种关系里得到什么？安全感、征服感、怜爱感、禁忌感、反差萌、命运感？
5. **拆机制**：什么机制反复制造这种关系？身份隐藏、契约、资源绑定、阶级差、战力差、记忆差、阵营对立？
6. **换外壳**：把 meme、关系和机制移入完全不同的职业、种族、技术、制度或世界规则中。
7. **增变量**：加入至少两个新的限制条件或代价，让它不只是换名词。
8. **删杂质**：凡是不能服务 meme 的酷炫要素，即使喜欢也要删掉。
9. **查可识别度**：如果读者能轻易说出原型，继续变形关系位置、权力结构、舞台和代价。

### 借鉴边界

可借鉴的不是作品名本身，而是底层结构：复杂成长体系、事件生成、政治形态、科技树、社会阶段、生存压力、资源管理、细致世界生成、人物关系网等。

某些 meme 与题材强绑定，例如部分赛博朋克的感受依赖资本、身体改造、技术异化、都市压迫等世界条件。遇到这种情况，不要强行迁移到完全无关的世界观；应先写出相近的社会结构或压迫机制，再迁移底层感受。
