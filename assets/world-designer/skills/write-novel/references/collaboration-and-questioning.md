# 创作前置拆解与用户协作

**适用层级**：主要用于 `L0-L1`，也可在进入 `L2` 前补关键缺口。
**解决问题**：前置拆解、一次一问、多方案比较、分块确认、进入执行前确认。
**不解决**：不直接负责章纲、正文或逐卷细节执行。
**缺前置时**：不确定当前层级时回看 `granularity-orchestration.md`；全书大纲级任务升级到 `grilling-and-consensus.md`。

## 创作前置拆解与询问法

写作任务不要一上来就生成正文或大纲。先像做设计一样拆问题：明确读者体验、约束、可选方向和验证标准，再进入执行。

本文件是所有任务的默认轻量协作：能假设就假设，能少问就少问。任务达到全书大纲级、或需要深挖用户爽点与隐性前提时，升级为 §Q2 拷问式访谈（grilling-and-consensus.md）——一次一问和多方案比较仍是它的基础动作，但提问密度、样例化程度和共识要求都更高。

### §C1 勘察上下文

在开始构思前，先快速确认已有材料：

- 用户已经给出的题材、人物、世界观、片段、聊天记录、偏好和禁忌。
- 当前作品最需要解决的问题：吸引点击、前三章留人、第一卷追读、人物关系、主线靶心、节奏疲软、世界观服务情节等。
- 哪些信息已经足够，哪些信息不足但可以先合理假设。
- 不要因为用户给了世界观就直接扩设定；先判断它服务哪种情绪和情节。

### §C2 一次一问

缺关键信息时，一次只问一个最影响方向的问题。优先级：

```text
目标读者乐趣 → 目标 meme → 主爆点 → 核心关系 → 情绪靶心 → 冲突来源 → 开局钩子 → 世界规则
```

提问要服务推进，不要为了“完整设定”而问无关问题。能通过合理假设继续的，就先假设并标注。

### §C3 多方案比较

面对题材、开局、主线、人物关系或世界观改造，不要只给一个答案。优先给 2-3 个方向：

```text
方案 A：强商业钩子，优点是点击和前三章强，风险是后期需要补深度。
方案 B：强关系张力，优点是人物黏性高，风险是开局需要事件托住。
方案 C：强议题/世界观，优点是回味和深度强，风险是前期容易慢。
推荐：选择 X，因为它最贴近当前目标读者乐趣和主爆点。
```

比较重点不是“哪个设定更酷”，而是哪个更能传达情绪、制造追读、承载 meme。

### §C4 分块确认

长篇设计要分块确认，不要一次生成不可控的大而全方案。

推荐确认顺序：

1. 核心乐趣与 meme。
2. 主爆点与情绪靶心。
3. 开头 3 章和前 10 章钩子。
4. 主角、关键关系、敌人或阻碍者。
5. 第一卷主线、伏笔和副爆点。
6. 必要世界观规则。
7. 章节或正文执行。

每一块都要说明“为什么这样设计能让读者继续看”。

### §C5 规格自检

在把方案交给用户前，自检：

- 是否存在空泛占位，例如“设计一个强敌”“制造悬念”但没有具体化？
- 是否有互相矛盾的设定、人物动机或情绪目标？
- 是否范围过大，一次想解决全书所有问题？
- 世界观是否开始反客为主，压过了情节和情绪？
- 是否只有情节摘要，没有读者情绪曲线？
- 是否给出了可执行的下一步，例如开头三章、第一卷大纲、人物矩阵或伏笔账本？

### §C6 转入执行

只有当核心设计被确认后，才进入具体生成：大纲、章节、场景、对白、世界观细节或改写。执行时仍要围绕已确认的 meme、主爆点、情绪靶心和读者留存目标，不要临时被酷炫设定带偏。

进入执行前，逐条确认核心设计成立（任一答不上，就回到对应粒度层补齐再动笔）：

- 读者为什么会点进来？（入口卖点 / 强钩子）
- 前三章为什么会继续看？第一卷为什么会养成追读习惯？
- 世界观具体服务哪种情绪和冲突，而不是独立堆料？
- 这段内容是否有新坑、预兆、伏笔或关系推进？
- 当前输出在哪一粒度层级，上一层最小约束是否已补齐？
- 全书大纲级任务是否已过 §Q2 的共识闸门？修改类任务是否已过 §Q7 共识护栏？
