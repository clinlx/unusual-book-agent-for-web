# 其他规则书：简易规则自建指南

当当前题材没有合适规则书，或只是复现某部小说/动画/游戏的风格时，主持人应先临时创建一份“够用即可”的简易规则，再回到原本的游戏流程中。

## 使用原则

- **短而可用**：只写本模组当前需要的规则，不追求完整系统。
- **先能裁定**：规则必须能回答“能不能做、怎么判、失败怎样”。
- **贴合题材**：规则服务时代背景、世界观和作品气质，而不是套通用模板。
- **避免拖慢**：不要长篇设定；缺失部分可在后续遇到时再补。

## 建议结构

1. **时代背景**：科技、社会、常识、危险等级。
2. **世界观定性**：超自然/魔法/科技/武力体系是否存在，普通人认知边界是什么。
3. **核心属性**：列出 3-6 个最常用属性，并说明用途。
4. **检定方式**：说明使用什么骰子、目标值如何定、成功/失败如何解释。
5. **战斗与对抗**：给出攻击、防御、伤害、受伤或失败后果的简化规则。
6. **特殊机制**：只写本题材最关键的机制，如理智、灵力、异能、污染、声望等。
7. **主持人裁定原则**：遇到未覆盖情况时，按题材逻辑、风险大小和叙事后果临时裁定。

## 输出要求

- 写成 Markdown，标题清晰，条目简短。
- 每条规则都要能被主持人直接执行。
- 不要生成庞大规则书；完成后立刻回到当前游戏任务。
