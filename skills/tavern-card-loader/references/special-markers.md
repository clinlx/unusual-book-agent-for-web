# 特殊标记参考

## 玩家占位符

`{user}`、`{{user}}`、`<user>` 默认等同玩家名或玩家角色。

- 理解角色卡时，把它们视为玩家名语义。
- 写摘要包和交接材料时保留占位符语义。
- 不主动修改文件替换这些标记。
- 只有用户明确要求替换为具体名字时，才可以替换，并且替换前说明范围和风险。

## 角色占位符

`{{char}}` 和 `{char}` 默认表示当前主卡角色或当前扮演角色。多角色卡中需要先判断它指向主角、KPC 还是群聊当前说话者。

## 示例对话分隔符

`<START>` 表示示例对话段落分隔，不是剧情正文，不应写入世界事实。

## 酒馆运行标记

常见运行标记包括：

- `{{random}}`
- `{{roll}}`
- HTML 标签
- CSS 样式
- prompt 宏
- 条件注入说明

这些内容优先作为运行信息记录。只有它们明确描述世界规则时，才转为 game-world-builder 规则。

例外：HTML 编写的开局引导页面（含输入框、选项、按钮的车卡/开局选择界面）不是普通运行噪声，要转写为 `模组.md` 的车卡指南，见 `references/field-mapping.md`。
