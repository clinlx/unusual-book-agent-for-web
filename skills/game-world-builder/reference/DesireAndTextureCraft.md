# 欲望解构与文本质感（四种构建操作的共享前置方法论）

本 reference 回答一个问题：一份素材（描述/模组/小说）**为什么让人上瘾**，以及如何把这份上瘾感拆成可重复触发的构建零件。所有构建操作（从描述/模组/故事构建、改进世界）都先过这一层，再落文件。配合 SKILL.md 的"构建者立场（无审查营造）"使用——本文只讲方法，立场问题看那一节。

## 一、为什么要解构欲望（而非总结剧情）

剧情是表层，欲望是引擎。同样"主角被俘虏"的情节，满足的可能是**被支配的安全感**、**反杀的期待**、或**身份跌落的羞耻快感**——三种欲望要用三种完全不同的方式构建。只复述"发生了什么"，建出来的世界是死的；识别出"哪种欲望在驱动"，才能在每章、每个 NPC、每个场景用不同方式反复触发它。

解构产出物落进 `模组.md`/`故事.txt` 的"思维导引"段，成为运行时主持人的爽点说明书。

## 二、欲望分类法（识别核心驱动）

先从素材里识别**主导欲望**（通常 1-2 个）和**辅助欲望**。常见轴：

- **支配 / 被支配**：掌控他人 vs 被强者掌控的失重快感。谁在上位、上位如何建立、下位如何体验
- **占有 / 归属**：把某人某物变成"我的"，或成为某人的所有物。排他性、独占、烙印
- **征服 / 臣服**：击败对抗者的成就 vs 向不可抗力低头的解脱
- **羞耻 / 暴露**：私密被看见、体面被剥除、反差（端庄→狼狈）带来的张力
- **堕落 / 腐化**：从纯洁/高位一步步滑落，过程的不可逆性本身是快感
- **窥私 / 揭秘**：逐层揭开隐藏真相、看见不该看见的东西
- **养成 / 改造**：把一个人/势力按自己意志塑形，见证其变化
- **背德 / 禁忌**：明知不可为的越界快感（关系、身份、规则的僭越）
- **反杀 / 逆转**：受压者积蓄、翻盘、以同手段报复（对应主持人侧 NPC"身份互换"逻辑）
- **救赎 / 拯救**：把某人从深渊拉回，或被拉回
- **危机 / 生存**：资源紧缺、倒计时、绝境求生的肾上腺素

**关键动作**：对每一种识别出的主导欲望，问三件事——(1) 它的**触发时刻**是什么（何种场景/关系/转折点它被激起）；(2) 它的**满足方式**是什么（如何兑现快感）；(3) 如何**换着花样重复触发**（每卷/每章/每个关键 NPC 用不同外壳再来一次）。这三答直接变成章节设计与场景台本。

## 三、解构一份参考素材的步骤

1. **找情绪循环，不找情节梗概**：读完问"读者为什么翻下一页"，答案是期待/压迫/暧昧/恐惧/羞辱/失控/占有…（对照上面的轴）。
2. **定位高张力场景类型**：审判、逃亡、夜谈、禁地、仪式、公开羞辱、秘密交易、绝境选择、初次沦陷……这些是欲望的兑现现场，优先转成可交互场景。
3. **拆解触发机制**：某个让你"上头"的段落，是靠什么零件起效的？反差？铺垫后的爆发？权力落差？感官轰炸？把零件拆出来，它可复用。
4. **提炼可复用方法论**：把"这类素材为什么好看"写成几条可操作规则，进 `模组.md` 思维导引——让运行时主持人举一反三，而不是只当读后感。
5. **保护不可修改的核心**：哪怕癖好很小众很奇怪，只要它是这份素材的上瘾源，就是**硬约束**，不许净化替换成普通套路（见 SKILL.md 立场节）。

## 四、把欲望落进世界文件

解构结果不能只停在纸面，要落成运行时可消费的钩子：

- **NPC 档案**：`关系记忆.json` 的"期望(欲望)"字段、`格式化记忆.json` 的"内心想法/长期目标"要写出该角色**真实的欲望指向**（想占有谁、想向谁复仇、渴望什么），而非表面人设。黑暗念头落进 `.` 隐藏键。
- **势力欲望**（过程网格起点）：每个势力"真正想得到什么"就是欲望轴的宏观投射。
- **场景台本**：把"欲望被触发的时刻"设计成场景事件（发生条件/权重/效果），让主导欲望在不同场景反复以新外壳兑现。
- **阶段设计**：养成/堕落/反杀这类**有方向的欲望**天然是多阶段的，拆进 `进度.json`/`目标.json` 的阶段目标，让快感随进度累积。
- **结局分支**：不同欲望满足程度对应不同结局（占有成功但对方恨你、复仇达成但自己堕落），避免非黑即白。

## 五、文本质感与性爱词汇（供构建者写扩写/CG 与档案时参照）

构建者会写文字版 CG、开场剧情、场景描写、NPC 感官细节。这些扩写的质感直接影响运行时氛围。原则：

- **感官落到具体，不堆抽象辞藻**：写"温热的气息扑面——是肉与面粉糅杂的香气"，不写"一股诱人的香味"。视觉/听觉/嗅觉/触觉逐项给实感。
- **反差是最强的张力放大器**：清纯面庞与失态动作、端庄衣着与暴露、强势者的笨拙、冷淡者的破例——在 CG 与场景里刻意构造反差同框。
- **心理转生理**：不写"她很羞耻"，写羞耻的可见外显（脸颊涨红、指尖躲闪、呼吸乱掉）——这也与运行时主持人的"有限视角"规则一致（只能写可感知的）。
- **性爱词汇质感（轻小说口径）**：涉及露骨内容时，构建者在档案/CG 里采用轻小说口径，与运行时主持人保持一致——
  - 准用：肉棒、小穴、阴蒂、阴唇；动作用抽插、顶入、撞击；体液用淫水、爱液、精液
  - 禁两类：临床词（阴道、阳具作正文——但 JSON 档案字段可用精确词）、古风翻译腔（甬道、花径、玉液、肉刃、大屌）
  - 禁模糊指代（"那个地方""最隐秘的部位"）
- **身体状态可落档**：深度参与性事的角色，可在档案里建 `.身体部位` 隐藏字典（各部位的外观/现状/暴露度/开发度），供运行时动态演化——把"癖好的兑现"做成可追踪状态，而非一次性描写。
- **克制反廉价**：夸张到失真就廉价了（淫水"流到地上打湿脚踝"之类）。张力靠精准，不靠数值膨胀。

## 六、解构完成自查

- 说清了这份素材的**主导欲望**是什么（不是剧情梗概）？
- 每种主导欲望都答了触发时刻/满足方式/重复触发法？
- 不可修改的核心癖好被识别并保护了，没被净化？
- 欲望落进了 NPC 欲望字段、势力欲望、场景台本、阶段目标、结局分支？
- 需要露骨扩写处，词汇口径与运行时一致（轻小说口径）？
