# 备团：情绪、注意力与公平推理

创建、转换或改进世界时使用。按题材准备可发生的场景与人物反应，不预定玩家的情绪、判断或行动顺序。推理题材另执行下文的公平性要求。

## 1. 情绪线：让结局承接此前的经历

为主要关系与核心冲突准备几个能实际游玩的变化：最初如何相处、什么值得在意、矛盾如何显露、选择付出什么、最后失去或保住什么。每个变化都要有具体事件、互动对象与触发条件，不能只标“感动”“压抑”“高潮”。阶段可因玩家选择改变、提前或缺席，不要求玩家按预定方式共情。

重要 NPC 在终局前应有建立印象、暴露矛盾与承担代价的机会。日常相处可以让玩家认识此人珍惜什么；压力下的选择再让玩家看见他为了什么愿意伤害关系、放弃利益或越过底线。结局回收实际发生过的承诺、争执和选择，不临时补一段悲惨身世来索取感情。

张弛来自关系与处境的变化：紧张后留出核实、交谈和消化的空间；再次施压时带来新后果。不要靠连续事故、反复阴森描写或不断提高音量维持情绪。

## 2. 注意力线：让玩家有理由追问

逐个关键节点准备“可观察事实 → 当前疑问 → 可以验证的方向 → 验证后改变的认识”。事实可以是说法与行动不一致、物件用途与所在位置不符、某人反常地维护一条规矩；出现须有世界内原因，不能仅用“似乎另有隐情”提示主持人知道答案。

场景围绕当前行动和最相关的疑问组织信息，保留玩家已经关注的对象，避免同时抛出一串无关谜团。引导提供可接触的人、可检查的痕迹或可核实的说法，给玩家形成假说的空间，不直接指出谁可疑、谁撒谎或应该得出哪个结论。玩家主动调查时如实交付其能获得的信息，不为了悬念故意含糊。

区分“文件里有”“有机会接触”“实际接触过”“玩家已作出判断”。备团只安排前两项；运行时后两项以实际经历和玩家表达为准。多人还要区分谁知道、谁亲历，预留自愿交流的机会，不把私密线索自动变成全队共识。漏过的线索只能通过有来源的后续接触再出现，不循环播放同一句暗示。

## 3. NPC 的偏执与背景：准备可见的行为依据

为重要 NPC 串起“过去发生过什么 → 他由此相信什么 → 现在执意保住什么 → 不肯接受什么 → 在压力下会做什么”。动机与秘密留在隐藏资料；另外准备玩家能够接触的行为、他人证言和实物痕迹，写明来源、出现条件与披露意愿。

偏执尤其要有具体对象、日常表现和真实代价，不能只写在 `.内心想法` 中。例如一个人坚持保留失踪者的座位，可以先在日常用餐中出现，之后因别人动了那把椅子发生争执；相关证言或旧物再提供过去的事实。行为本身允许多种解释，不由旁白提前判定其心理原因或罪责。

主要人物应有不围绕谜底运转的生活与关系，不能个个欲言又止。背景披露可以分散在相处、冲突和调查中，保密程度随实际信任、利益与压力变化；不默认只有逼供或临终独白才能让背景进入玩家经历。

## 4. 本格推理：事实固定，推断开放

- 备团先固定核心真相、时间线、人物行动、手段及物理或超自然规则。为关键结论写清支持证据、可能的替代解释，以及区分这些解释所需的证据。原模组不足以唯一推出的部分，要补足合理证据或明确保留不确定性，不能宣称已有唯一解。
- 决定性事实与必要规则须在解答前有合理可达的获取途径。不能到结局才加入新人物、隐藏通道、未知能力或关键前史，使先前推理失效；超自然题材也须预先提供可验证的规则迹象。不得根据玩家猜测更换真凶、改写既有证据或倒改已经发生的事实。
- 玩家推理依赖可核验的事实。NPC 可以撒谎、误认或隐瞒，但须写明原因与能够核对的矛盾；普通叙述不谎报玩家已经确认的观察。误导来自事实的合理歧义与人物行为，不能靠主持人扣住本应得到的信息。角色的偏执或悲惨身世可以解释行为，不能单独代替定罪证据。
- 避免把唯一关键证据锁在一次检定或一个关键词后。保留原模组的检定及成败后果，必要时在备团阶段补充有独立来源的替代证据；失败可增加时间、风险或信息不完整的代价。备用来源必须确实能知道或留下相应信息，不凭玩家走到哪里就把同一件物证搬到哪里，更不能制造违背时间线的证言。
- 玩家提前推对、绕过预定顺序或提出有效实验时，依事实回应，不为保留反转强制失败或封路。解答应让人能回看前面的证据理解其含义，不依赖 NPC 在最后一次性报出全部谜底。

## 5. 落位与预演

把实际运行所需的关系变化、披露条件、注意力承接和证据关系写入既有的主线/章节剧情、场景台本与 NPC 隐藏资料，并建立必要索引；不另建逐回合日志或把完整设定重复抄到多处。公开物品与人物字段只保留玩家可见事实，不夹带“伏笔”“引导玩家怀疑”等幕后说明。

预演时遮住隐藏设定，只用玩家沿这条路线实际可获得的信息走一遍。检查：玩家为何在意此人，能提出什么疑问，凭什么验证，结局回应了哪些实际经历。再走一次错过主要线索、一次提前推对或拒绝继续的路径。发现铺垫不足时，修正此前可接触的场景与证据；不靠结局补课、强制回头或无限延长故事掩盖缺口。玩家仍可选择不完美结束。
