# 开场执笔法

**用途**：写 `样例开场.md` 正文时的执笔标准。因为 `样例开场.md` 兼作运行时主持人的全程文风范本，本文同时也是这个世界的文风纪律——它写成什么样，整局就会被带成什么样。
**不解决**：不决定开局类型、留白范围、开局配置面板的内容——那些是 SKILL.md「开场双文本」的交付契约；也不负责欲望解构与爽点设计（见 [DesireAndTextureCraft.md](./DesireAndTextureCraft.md)）。
**编号作用域**：§O 仅指本文的开场写作条目。

条目：§O1 开场是一个场景 ｜ §O2 经历者不是讲述者 ｜ §O3 世界观靠行动喂 ｜ §O4 开场骨架 ｜ §O5 共鸣三检 ｜ §O6 闲笔许可 ｜ §O7 句式黑名单 ｜ §O8 开局禁忌与可用形态

**动笔顺序**：§O4 定骨架 → §O1 立住场景 → §O2/§O3 落笔 → 成稿后按 §O7 扫句式、按 §O5 验收。姿态错了，句子打磨得再好也是解说词；场景没立住，细节根本没有落点。

## §O1 开场是一个场景，不是一次场景巡览

这是"每一段都是某个物件描述或伏笔"的病根。开场的原子单位是**场景**：一个空间 + 一段连续时间 + 固定的几个在场者。戏在这个盒子里演到有名堂，才准换景。800~1500 字通常**只够一个场景，至多两个**——开场里出现三个以上地点，几乎必然每个都没立住。

**立盒子**（用主角的感官立，不是作者报幕）：这是哪里、多大、什么光线气味声音、"你"站在哪个位置；谁已经在场、各自在干什么、离你多远；你带着什么情绪和目的走进来。两三笔即可，可以揉进动作里（推开门，霉味先涌出来），但不能省——省了，后面的对白就悬在真空里。

**驻场**：对白不是台词接力。两句之间要有停顿、动作、视线移动、环境的持续在场（窗外的雨一直在下）。人物在空间里移动、拿起东西、靠近或退开——距离变化本身就是关系语言。一场戏从头到尾没人动过位置，说明空间没被用起来。

**退化形态**：摘要冒充场景——"你到了旅店，向老板打听了消息，然后上楼休息"。三步就完成的不是场景，是事件登记。判据：读的人能不能在脑子里搭出这个空间、把人摆进去？搭不出来，就还没进场。

## §O2 叙事姿态：经历者，不是讲述者

开场最常见的失败不是文笔差，是姿态错位：主角在经历，叙述者却站在旁边解说、总结、升华。默认姿态：**读者附身在主角的感官和念头上，只看得到他看到的、听得到他听到的、想得到他想到的。**

三种越位：

1. **上帝视角泄漏**：写出主角不可能知道的事。禁句族："而他不知道的是……""在他看不见的角落……""此刻的他还不知道……""没人发现他在撒谎"。主角看不见的，最多写成他的感知痕迹（后颈发凉、对方的眼神比平时多停了一秒）。
2. **叙述者总结陈词**："这一夜改变了一切""命运的齿轮开始转动"——作者跳出来替读者定性事件的分量。分量由读者从场景里自己称出来，不由旁白宣布。
3. **咀嚼式升华**：事情发生后，用排比、比喻和拔高的书面语反复回味它有多严重。判断要短、要快、要继续走：一次即时反应就够，不回味、不展开、不押韵。

**加引号测试**：把内心活动加上引号读一遍，像不像这个人真会对自己说的话？不像就重写。允许大段思维——长短不是问题，主语才是问题：必须是他在想，不是作者在替他想。

**一件事只讲一次**：不要"行动 → 解释意义 → 收尾总结"三连。行动本身 + 至多一句即时身体反应或短念头，然后走下一拍。

- 过载：`你转身离开。你能感觉到他的目光跟着你。你意识到自己刚才的回答暴露了太多。第一道裂缝已经出现了。`
- 干净：`你转身离开。没回头。心跳很快。`

## §O3 世界观靠行动喂，不靠交代喂

设定不是在开场"介绍"的，是读者跟着主角在处境里**撞见**的。同一份信息，交代出来是解说腔，撞出来就是剧情。

- 交代：`这座城由三大商会共治，教会名义上超然，实际收着最大的一份税。`
- 撞见：`守卫收了钱才让开。第二道门的人也伸了手——袖口露出教会的银徽，你把剩下的钱又数了一遍。`

后者一个机构名都没提全，权力结构却已经立住，而且是读者自己推出来的，比被告知记得牢。

**颗粒度**：开场只释放读者理解**下一拍**所必需的那一小块。以后才用得上的，留到用得上的场景。前史、势力谱系、纪元大事，不要在开场用一段旁白倒完。

**转场靠因果，不靠宣布**：人不会凭空出现在下一个地点。"第二天他决定去码头"是宣布；把决定写成动作和对白，才是推出来的。找不到因果链的时候，缺的是一拍行动，不是一句解释。

## §O4 开场骨架：先事件，后背景

顺序错了，文笔再好也救不回来。可直接套用：

```text
两句话交代身份与处境 → 立刻卷入异常/危机/交锋 → 在应对中显露主角的能力、缺陷或欲望
→ 抛出一个更大的疑问 → 停在玩家能行动的当口
```

背景**排在最后**，而且只补必要的那一点。几句勇者与魔王的对白，就足以让人明白这场冲突的起点、双方的立场和力量差——不必先讲大陆与纪元（→§O3）。

**与"娓娓道来"不冲突**：这两条管的不是同一件事。娓娓道来管的是**信息投放速度**（伏笔别一次倒完、支线人物别都来露个脸）；本条管的是**此刻有没有事正在发生**。一个开场完全可以既有事发生、又不倒设定——那正是目标形态。

**结尾把行动权交出去**：停在一个具体的当口——有人在等你回答、有东西正在逼近、有一扇门在你面前。不要停在感慨、总结或景物余韵上。

## §O5 共鸣三检（开场验收）

写完通读一遍，三项同时成立才算过：

1. **感兴趣**：读的人想不想知道接下来怎么了？
2. **关心**：他在乎这个主角和结果，还是在事不关己地围观？
3. **理解**：他明不明白**正在发生什么、为什么要紧**？看不懂的冲突再激烈也只是噪音。

第 3 项就是"引入世界观"的真实标准——判的不是交代了多少设定，而是读的人站不站得住脚。

## §O6 闲笔许可：不是每个物件都是伏笔

"每一段不用看都知道，必然是某个真实存在的物件或者伏笔"——这是把世界写成了布景板，读者闻得出来。真实感恰恰来自**无用细节**：街上的人烟、雨后的气味、路人的私语、远处的犬吠、屋里的旧陈设。它们不服务任何钩子，它们的功能就是证明这个世界不是为这一局临时搭出来的。

- 不重要的物品、景物、路人**不受设定账本约束**，主角的注意力扫过什么就可以写什么——前提是过 §O2（是他在看）。
- 氛围靠气味、声音、触觉叠出来，不靠形容词宣布（→§O7 程度副词）。
- 闲笔是调味不是主菜：连续多段闲笔而没有推进时，回 §O1 检查场景立住了没有。

## §O7 句式黑名单（成稿后扫一遍）

单句无害，成篇之后读者会闻到机翻感。改写方向一律是：**删掉否定或修饰的那半句，把留下的半句写具体**——否定不产生画面，具体细节才产生。

- **转折定义式**："不是A，而是B""与其说A不如说B""这不是X，这是Y"。直接写 B，不靠否定 A 来定义 B。用"某种""一丝说不清的""难以名状的"逃避写具体，是同族毛病，删掉限定词逼自己写出那到底是什么。
- **否定排比式**："没有A，没有B，甚至没有C"。用不存在的东西堆气氛，不如写一个存在的：不写"屋里没有一点声音"，写"静得能听见挂钟的秒针"。**豁免**：角色对白里承担真实语义的对比是人话（"我要的不是钱，是道歉"），不在此列；被禁的是旁白里作为修辞习惯的高频复现。
- **程度副词**："极其""非常""无比"是宣布强度，不是呈现强度。侧面写——不写"非常痛"，写指甲掐进掌心。
- **比喻纪律**：旁白即主角的心智，比喻必须出自这个人的认知和词汇。农夫可以觉得云像羊群，不能觉得云像巴洛克穹顶——后者是作者在替他打比方，属于姿态越位。拿不准就降级成他的直接念头或台词，让比喻的主人显形。

成稿后扫，不要边写边扫——句式自检是终稿工序，前置会打断行文节奏。

## §O8 开局禁忌与可用形态

**禁忌**（除非第一时间就卷入异常）：从出生或幼年写起；赶路三段而无事发生；单纯的日常起居；**主角独自醒来后环视房间、逐件清点物品**。最后一种最常见，也最要命——它天然导向"一段一个物件描述"，正是本文要治的病。

**可用形态**（挑一个，不要叠加）：

- 主角被误认、指控、追捕、传唤，必须先应付眼前这一关。
- 主角撞进正在发生的现场：仪式、命案、交锋、异象。
- 主角刚得到一样看似走运的东西，当场发现它带着代价。
- 主角与一个强关系钩子人物照面，立刻产生亏欠、敌意、隐瞒或依赖。

**固定开局的例外**：以 `开场剧情.txt` 原文为主体时，本条不约束原文部分——原文照录不改写；只约束你自己写的衔接扩写。
